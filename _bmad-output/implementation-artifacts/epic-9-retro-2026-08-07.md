# Epic 9 Retrospective: Fast MAF Primary Cutover

Date: 2026-08-07
Project: enTalentNew
Epic Status: complete
Retrospective Status: complete

## Epic Review

Story 9.1 established the first production-path MAF runtime switch (`maf_primary`) and moved the user-facing response path for conversations through the Python Microsoft Agent Framework in a controlled, reversible manner.

Primary outcomes:
- Added explicit `maf_runtime_primary` control and `maf_primary` runtime mode with precedence handling.
- Implemented TypeScript-owned primary adapter that preserves existing side-effect ownership (outbound persistence, Slack outbox, risk/escalation, style/evidence handling) while using Python runtime output as the reply/risk candidate source.
- Kept `maf_shadow` and `maf_canary` behavior unchanged where those modes are selected.
- Added fallback-before-commit safety behavior for config, HTTP/client validation, and timeout failure cases.
- Added `pnpm maf:primary:smoke` and preserved `pnpm maf:shadow:smoke` precondition.

- Scope was implemented quickly and within story boundaries.

- Non-local deployment and real production rollout checks were intentionally left out in this slice.
