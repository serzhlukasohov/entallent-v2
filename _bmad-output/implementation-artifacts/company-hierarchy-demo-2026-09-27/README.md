# Company Hierarchy — team demo

Public site: https://site-production-7b9a.up.railway.app/

For offline use, open `index.html` in a browser. No internet connection or installation is needed; the screenshots are stored beside the page.

- Use `←` / `→` or the buttons at the bottom to move through the six slides.
- Press `1`–`6` to jump to a slide.
- Select a numbered callout on a screenshot to read its explanation. "Enlarge screenshot" opens the full-size image.
- Select `⛶` to enter full-screen mode.

The presentation takes about 5–6 minutes. Suggested speaker notes are in `presenter-notes.md`.

The screenshots contain test names and internal pilot identifiers. Anyone with the Railway URL can access the site, so share it only within the team.
