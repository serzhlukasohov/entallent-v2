## Findings that require a spine change

1. **AD-7 uses a deprecated API.** `generateObject` is marked `@deprecated` in the `ai@6.0.240` typings the repo already ships; the supported pattern is `generateText` with `output: Output.object({ schema })` and `result.output`. The spine's Verification Note says only that `generateObject` "exports", which is true but misses the deprecation. Rewrite AD-7 and the Verification Note; add the `strictJsonSchema` default note for the verdict schema.
2. **`@langwatch/scenario` is two majors behind and the spine does not say so.** Current is 1.7.0 (2026-10-07); `^0.4.15` will never resolve to it. The APIs the spine relies on are unchanged across 0.5/1.0/1.7 per the changelog, so the design holds, but the Stack table and a Deferred row must reflect the real line.
3. **AD-14 `/dev` contract is incomplete and misses the `api/v1` prefix.** Real paths are `/api/v1/dev/...`; `reset-user` needs internal `userId` + `tenantId` (so `find-conversation` must run first); the turn-injection endpoint `POST /dev/simulate-message` is not named at all.
4. **DevModule gating is "not production", not "development".** `shouldMountDevModule()` mounts the module for any `NODE_ENV` except `production`. Replace the "not re-verified" Verification Note and make AD-15's L2 job explicit that `api` must not run with `NODE_ENV=production`.
5. **zod pin should be stated as a deliberate choice.** `ai` 6 and 7 accept `^3.25.76 || ^4.1.8`; 3.25.76 is the exact lower bound. Pinning `^3.25.76` is correct and keeps one `ai(zod)` instance in the lockfile, but the spine should say why and warn against choosing zod 4 for this package alone.
